# 자동차 경주

##  핵심 기능

* **입력**: 쉼표(`,`)로 구분된 자동차 이름과 시도할 횟수를 입력받습니다.
* **이동**: 0\~9 사이의 무작위 값을 생성하여, **4 이상일 경우** 자동차가 1칸 전진합니다.
* **출력**: 매 시도마다 모든 자동차의 현재 위치를 `-`로 시각화하여 출력합니다.
* **우승자 판별**: 모든 시도 종료 후, 가장 많이 전진한 자동차를 우승자로 선정합니다.
* **다중 우승자**: 공동 우승자가 발생할 경우, 쉼표(`,`)로 구분하여 모두 출력합니다.

***

##  설계 및 리팩토링

* **객체 지향 설계**: `static` 변수 사용을 지양하고, `Application` 클래스의 인스턴스 필드(`HashMap`, `List` 등)를 사용하여 경기 상태를 관리합니다.
* **테스트 독립성 확보**: 각 테스트가 `new Application().run()`을 호출하도록 하여, `static` 상태 공유로 인한 테스트 오염 문제를 해결하고 독립적인 테스트 환경을 보장합니다.
* **메서드 분리**: indent depth 2를 준수하기 위해 `mapping`, `moveCar`, `raceStart` 등 핵심 로직을 별도의 메서드로 분리하여 가독성을 높였습니다.

## ️ 예외 처리 및 유효성 검증

안정적인 프로그램 실행을 위해 다음과 같은 예외 상황을 처리하고, `IllegalArgumentException` 또는 `NumberFormatException`을 발생시킵니다.

### [자동차 이름]

* `예외_테스트`: 이름이 **5자를 초과**하는 경우
* `예외_테스트4`: 이름 앞에 쉼표가 오는 경우 (예: `,pobi`)
* `예외_테스트5`: 이름 뒤에 쉼표가 오는 경우 (예: `pobi,`)
* `예외_테스트6`: 쉼표가 **연속으로 입력**되는 경우 (예: `pobi,,,woni`)
* `예외_테스트7`: **중복된 이름**이 존재하는 경우


### [시도 횟수]

* `예외_테스트2`: **숫자가 아닌 값**(문자 등)을 입력한 경우
* `예외_테스트3`: **음수 값**을 입력한 경우
