# 자동차 경주

## 🚀 기능 목록
- 경주할 자동차 정보들의 입력과 시도할 횟수를 입력 받는다.
- 랜덤함수를 통해 자동차들의 전진여부를 구현한다.
- 우승자를 출력하는 기능을 구현한다.
- 구현한 기능들과 예외에 대하여 테스트 코드를 구현한다.
- 위 과정에서 발생하는 예외들을 발견 시 예외처리를 추가한다.

## ✍️ 커밋 메시지 컨벤션

- `feat`: 새로운 기능 추가
- `fix`: 버그 수정
- `ref`: 코드 리팩토링 (기능 변경 없이 코드 구조 개선)
- `docs`: 문서 수정 (README.md 등)
- `test`: 테스트 코드 추가 또는 수정
